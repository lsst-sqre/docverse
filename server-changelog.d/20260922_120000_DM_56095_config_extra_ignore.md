### Other changes

- The keeper-sync config request and response schemas are now distinct in the OpenAPI document: `PUT /orgs/{org}/keeper-sync` takes a `KeeperSyncConfigWrite` body, which forbids unknown fields exactly as before, while the response `KeeperSyncConfig` ignores them. The response model's tolerance is what lets a server rolled back to an earlier release still load an organization whose config row a newer server wrote — previously the first write of a new scope field made that row unreadable to the older code.
