### Other changes

- A keeper-sync tombstone written by a lifecycle rule now names the rule that fired. Every lifecycle soft-delete — the `lifecycle_eval` worker, the daily `git_ref_audit`, the GitHub `delete` webhook, the default-branch duplicate-draft retirement, and keeper-sync's proactive pre-import pass — sets the tombstone's `tombstone_note` to the matched rule's type (`draft_inactivity` or `ref_deleted`), so `GET /orgs/{org}/keeper-sync/tombstones` shows which rule retired an edition. A `manual_delete` tombstone from the edition `DELETE` endpoint keeps an empty note. Tombstones recorded before this change are not backfilled.
