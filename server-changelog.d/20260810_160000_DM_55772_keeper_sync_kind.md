### Bug fixes

- Keeper-sync no longer imports every non-`main` LTD edition as a `draft`. `derive_edition_kind()` is now mode-first: LTD editions tracking `lsst_doc`, `eups_major_release`, or `eups_weekly_release` map straight onto `release`, `eups_daily_release` stays `draft`, and `git_refs` / `manual` editions run the full slug-rewrite rule chain (org/project rules plus the built-in version heuristics) against the ref their Docverse tracking pins, falling back to the LTD slug when there is no ref. LTD's `main` edition still maps onto `EditionKind.main`.
- The keeper-sync preemptive lifecycle pass stops tombstoning version-slugged LTD editions `lifecycle_preemptive` before they are ever imported. The transient edition it evaluates now carries the same derived kind as the import path, so `draft_inactivity` no longer matches old LTD releases regardless of their `date_rebuilt` age. Already-tombstoned editions are not re-imported automatically — an operator must delete the `lifecycle_preemptive` tombstones and re-run the sync.
