### New features

- `GET /orgs/{org}/projects` now embeds each project's default (`__main`) edition as `default_edition` on every row, on the ordered listing and the `q` search path alike, using one batched query per page. A poller such as Ook reads every changed project's current build and `published_url` from the listing alone instead of following up with one `GET /orgs/{org}/projects/{project}` per row. A soft-deleted project's row keeps `default_edition: null`, matching the single GET. The listing's weak `ETag` still tracks project clocks only: a repoint of the default edition retires it, a configuration-only edit to the edition (title, tracking, `publish_status`) does not; consumers that need the edition's configuration read the single project, whose tag covers the edition's own clock.
