### New features

- Auto-created editions now derive `kind=release` from version-like git refs even when a project has no slug-rewrite rules configured. Four new rule types — `semver`, `lsst_doc`, `eups_major`, and `eups_weekly` — join the `slug_rewrite_rules` discriminated union, and a built-in list of them is consulted after any org/project-configured rules and before the draft fallback. Stable semver (`1.2.3`, `v1.2.3`), lsstdoc (`v1.0`, `1.0`), EUPS major (`v27_0`), and EUPS weekly (`w_2026_10`) refs derive releases; semver prereleases, EUPS dailies, and ticket branches still fall through to `draft`. Slugs and `git_ref` tracking are unchanged — only the edition kind is affected — and an explicit user rule always wins. The rule types are also accepted in org/project `slug_rewrite_rules` payloads, so operators can override kinds or reorder matching, and the edition-tracking derivation log now records the `matched_rule_type`.
