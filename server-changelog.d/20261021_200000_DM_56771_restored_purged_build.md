### Bug fixes

- Keeper-sync no longer enqueues a `publish_edition` job for a restored edition whose current build the purgatory sweep has reclaimed. A `lifecycle_delete` edition can stay retired long enough for its build to be purged; when LTD's rebuild then clears the tombstone and the visit's build sync short-circuits on that build, the republish used to fail copying objects that no longer exist, into Sentry and the publish reaper, once per restore. The edition is now restored unpublished, with the same "Restored edition without republishing; its current build is not live" warning (`build_deleted`, `build_purged`) the admin edition restore logs; both paths share one guard. `publish_edition` also refuses a build with `date_purged` set at pickup, completing the job with a `purged_skipped` progress flag rather than failing it.
