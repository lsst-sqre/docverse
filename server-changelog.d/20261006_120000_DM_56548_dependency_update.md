### Other changes

- Update dependencies. SQLAlchemy 2.0 → 2.1 is the notable bump: the storage layer no longer calls the deprecated `Result.tuples()`, its `Select` annotations use SQLAlchemy 2.1's variadic form, and three queries narrow the nullable columns that 2.1's precise `Row` typing now surfaces. Also safir 15.2.2, alembic 1.20, FastAPI 0.142, Starlette 1.7, rubin-repertoire 3.0, mypy 2.4, ruff 0.16.10 and uv 0.12.23. `alembic.ini` sets `path_separator = os` to silence Alembic's legacy `prepend_sys_path` splitting warning.
