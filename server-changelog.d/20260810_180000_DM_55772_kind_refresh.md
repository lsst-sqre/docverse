### Bug fixes

- Keeper-sync now recomputes an existing edition's kind on every sync and applies it as a promote-only change, so editions imported as `draft` before the derivation was fixed heal to `release` on the next tier poll instead of needing an operator PATCH. Only `draft` → `release` is ever written: kinds are never demoted, `main` / `major` / `minor` / `alternate` editions are never rewritten, and a kind set by hand through the editions PATCH API survives every subsequent sync. Editions adopted by `git_ref` under a different slug are refreshed on the same terms. Each promotion emits a `Promoted keeper-sync edition kind` log event carrying the previous kind and the derivation's source.
