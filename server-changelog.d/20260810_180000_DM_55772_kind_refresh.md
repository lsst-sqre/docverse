### Bug fixes

- Keeper-sync now recomputes an existing edition's kind on every sync and converges the row on it, so editions imported as `draft` before the derivation was fixed heal to `release` on the next tier poll instead of needing an operator PATCH. Convergence runs in both directions: a `release` that the old mode mapping produced for a branch-tracking edition heals back to `draft`, so a wrong classification is no longer permanent. Only editions Docverse owns are rewritten — those whose `kind_source` is `derived` — and only within the derivation's own vocabulary, so `major` / `minor` / `alternate` rows, which other derivations own, are never disturbed. Editions adopted by `git_ref` under a different slug are refreshed on the same terms. Each change emits a `Converged edition kind` log event carrying the previous kind, the new kind, and the derivation's source.
