### Bug fixes

- Keeper-sync's semver aggregate backfill no longer fails with "create_internal lost ON CONFLICT race", captured to Sentry, when a soft-deleted edition still holds an `N` or `N.M` slug a synced release needs. It now settles the slug as native edition tracking does: a lifecycle-deleted (or unrecorded) edition already on the aggregate's tracking mode is revived in place and pointed at the release; an edition on another tracking mode stays deleted and the aggregate is skipped with the info line "Semver aggregate slug held by a non-aggregate edition; leaving it untouched" (`edition_deleted` true), the line both aggregate paths now write for a live holder too (`edition_deleted` false); and an operator-deleted edition stays deleted with the warning "Semver aggregate slug reserved by manual delete; aggregate not backfilled".
