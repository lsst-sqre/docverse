### Other changes

- Keeper-sync scope resolution now walks the LTD product listing once instead of twice. The worker previously derived the `excluded_count` on the "Resolved keeper-sync run scope" and "Resolved keeper-sync tier scope" events by copying the config with its exclude fields stripped and re-filtering the entire listing — two full compile-and-match passes over ~1,645 slugs on every `main` tier tick, to populate one log field. It now calls the config model's single classifying pass, which returns the in-scope slugs and that count together. The logged counts are unchanged.
