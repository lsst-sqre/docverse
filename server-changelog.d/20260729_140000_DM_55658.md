### Backwards-incompatible changes

- The server distribution is renamed from `docverse` to `docverse-server` with a top-level `docverse_server` module, leaving the `docverse` import root to the client library. The PEP 420 namespace-package layout is gone: both packages are now regular packages. The `docverse-admin` CLI script name and the Docker-only deployment model are unchanged. Release tags use the `server/` prefix (e.g. `server/0.1.0`), and CI pushes Docker images only for `server/`-prefixed release tags.
