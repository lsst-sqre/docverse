### Other changes

- The minimum supported `httpx` version is raised from 0.25 to 0.26. httpx 0.25 pins `httpcore<0.19`, and `httpcore` 0.18's anyio backend evaluates `anyio.abc.ByteStream` eagerly at class-definition time. anyio 4.15.0 made `anyio.abc` a lazily imported submodule, so importing `httpcore` before anything else imports `anyio.abc` raises `AttributeError: module 'anyio' has no attribute 'abc'`. httpx 0.26 requires `httpcore` 1.x, whose anyio backend uses postponed annotations and is unaffected.
