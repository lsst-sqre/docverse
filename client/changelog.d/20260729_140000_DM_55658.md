### Backwards-incompatible changes

- The client distribution is renamed from `docverse-client` to `docverse` and now owns the plain `docverse` import root as a regular package. Import the client as `from docverse import DocverseClient` and models as `from docverse.models import Project`; the `docverse.client` module path is gone. The `docverse` CLI script name is unchanged. Release tags use the `client/` prefix (e.g. `client/0.1.0`).
