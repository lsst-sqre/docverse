### New features

- `DocverseClient.restore_edition(org, project, edition)` restores a soft-deleted edition, whether an admin deleted it or a lifecycle rule retired it, and returns it. The server republishes the edition's current build (its `publish_status` comes back `pending`) unless that build was itself deleted or purged. An edition that is not deleted raises `DocverseClientError` with `status_code` 404.
