### New features

- `KeeperSyncConfig` gains `resolve_scope(slugs)`, which classifies LTD project slugs against the sync scope in a single pass and returns both the order-preserving in-scope list and the number of slugs an include rule admitted but an exclude rule then removed. `filter_in_scope` is now a thin wrapper over it, so the rule — includes, then excludes, `re.fullmatch`, case-sensitive — is unchanged.

### Other changes

- Compiled scope patterns are now memoized on the pattern list, so `is_in_scope` and `filter_in_scope` no longer recompile every entry of `project_slug_patterns` and `exclude_project_slug_patterns` on each call. The cache is keyed on the pattern strings rather than held on the model instance, so it stays correct when the pattern fields change, it is shared by configs parsed fresh from the stored JSONB, and it leaves `KeeperSyncConfig` equality untouched.
