### New features

- `DocverseClient.restore_build(org, project, build)` restores a soft-deleted build and returns it. The build's status is not changed — one deleted before it finished comes back `cancelled` — since a restore recovers the row and its content rather than re-running the build. A build whose content has already been reclaimed raises `DocverseClientError` with `status_code` 409; check `Build.date_purged` before assuming a deleted build can be brought back.
