### New features

- Added `EditionKindSource` (exported from `docverse.models`), the `derived` | `declared` enum behind the new `kind_source` field on `Edition` and `EditionUpdate`. `derived` means Docverse owns the edition's `kind` and recomputes it from the edition's ref and the project's slug-rewrite rules on every sync and tracked build; `declared` means an operator set it and no automated path rewrites it. The field is read-only on `Edition` — a kind becomes `declared` by PATCHing `kind` to a *different* value — and settable on `EditionUpdate` so a declared kind can be handed back to Docverse with `EditionUpdate(kind_source=EditionKindSource.derived)`.
- `EditionUpdate.kind` no longer pins an edition when it merely echoes the kind the edition already has, so a read-modify-write client that round-trips a full `Edition` no longer opts editions out of automatic kind derivation as a side effect.
