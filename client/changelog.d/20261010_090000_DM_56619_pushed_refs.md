### New features

- `KeeperSyncProjectStatus` gains `pushed_refs` and `in_push_window`, reporting the keeper-sync push hot path. `pushed_refs` lists the refs GitHub pushes have stamped on the project, newest push first, each a new `KeeperSyncPushedRef` with its `git_ref`, `date_pushed`, and `in_window`, whether that push still holds the project on the tier crons' fast path. `in_push_window` is true while any of them does. The two default to an empty list and `false`, so a response from a server that predates them still parses, meaning what it did: a project no push had stamped.
