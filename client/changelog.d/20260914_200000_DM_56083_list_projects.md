### New features

- New `DocverseClient.list_projects(org, ...)` returns an organization's whole project listing as a `ProjectList`, walking the `Link rel="next"` chain so paging is the client's problem rather than the caller's. It forwards `updated_since` (as an ISO 8601 timestamp with its offset), `include_deleted`, and `order`, and takes an `if_none_match` validator that it sends on the first request alone — a precondition describes the page the caller already holds, not the cursor URLs that follow. The result carries the first page's `etag` back verbatim for the next poll; a 304 there yields `not_modified=True` with an empty `projects` list and no further requests.
