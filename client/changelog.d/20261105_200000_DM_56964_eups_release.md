### New features

- New `TrackingMode.eups_release` value (`"eups_release"`) for editions that follow the latest final EUPS release tag, such as `v30_0_12` or the two-component `v17_0`. It is accepted anywhere a tracking mode is: `EditionCreate`, `EditionUpdate` and `DefaultEditionConfig`. Release candidates (`v30_0_12_rc3`) and weekly or daily tags never advance an edition in this mode. Older clients that receive the value from a newer server fail to validate it, so upgrade the client before reading editions that use it.
