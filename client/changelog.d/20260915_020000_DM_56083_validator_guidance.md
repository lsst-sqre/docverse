### Other changes

- `ProjectList.etag` and `ProjectList.last_modified` now say which validator to poll with. `etag` is the primary one — it is derived from the listing watermark at full precision, so it notices a change however soon after the previous one it landed. `last_modified` is documented as the fallback for a caller holding no ETag, along with the reason: an HTTP date names a whole second, so the server refuses it as a validator while that second is still open and answers such a poll in full.
