### New features

- New `KeeperSyncScopePreview` model, the response body of `POST /orgs/{org}/keeper-sync/scope-preview`. It reports what a keeper-sync scope resolves to against the live LTD product listing: `ltd_count` and `in_scope_count`, the resolved `in_scope_slugs` in LTD listing order, `new_slugs` (in-scope slugs with no keeper-sync state row yet), `tombstoned_slugs` (in scope by config but skipped for a tombstone), and `unmatched_project_slugs` (configured exact slugs the LTD listing does not contain). Every slug list defaults to empty, so only the two counts are required.
