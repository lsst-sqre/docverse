### New features

- New `KeeperSyncScopePreview` model, the response body of `POST /orgs/{org}/keeper-sync/scope-preview`. It reports what a keeper-sync scope resolves to against the live LTD product listing: `ltd_count` and `in_scope_count`, the resolved `in_scope_slugs` in LTD listing order, `new_slugs` (in-scope slugs with no keeper-sync state row yet), `tombstoned_slugs` (in scope by config but skipped for a tombstone), and one typo-catching list per exact-slug config field — `unmatched_project_slugs` (`project_slugs` entries the LTD listing does not contain) and `unmatched_exclude_project_slugs` (`exclude_project_slugs` entries it does not contain). The two are reported separately because a miss reads differently on each: an unmatched include admits nothing, while an unmatched exclude holds nothing back and so lets the product it was meant to stop sync anyway. Every slug list defaults to empty, so only the two counts are required.
